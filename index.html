Your Lyrion library,
instant and bit-perfect.

A Windows app that browses, searches and plays music from any Lyrion Music Server. No server plugins, no settings changed, and you never open the server’s web page.

Made for big, careful collections

Especially jazz and classical, where artist and album aren’t enough.

Instant, however big the library

  • The library is cached on your PC and kept in sync, so search-as-you-type is instant over any connection.
  • Search by tag, grouped by folder: every hit shows up as the CD or LP it belongs to.
  • Browse by composer, performer, conductor or ensemble, as well as artist and album.

Browse your way

  • Group, sort and switch views on every list.
  • Top-level lists can show how many albums each artist, genre or composer has.
  • Press and hold anywhere to select several things, then act on them from the bar at the bottom.
  • Build a playlist while you browse anywhere in the library.

Now playing, properly

  • Artist biography and timeline, album reviews and background, beside the cover.
  • Per-track credits: who played what, on every track.
  • Synced lyrics, line by line.

A hi-fi on your desktop

  • Analogue VU meters, power meters and a spectrum analyser.
  • A graphic equaliser and pre-amp, with a warning before anything clips.
  • Frosted glass or tinted with the album cover.

Hi-fi mode

  • Turn the window into a piece of hi-fi: power meters, a dot-matrix display, transport keys and a volume knob.

Bit-perfect

  • Plays through the built-in Squeezelite player, straight to your DAC.
  • Exclusive mode bypasses the Windows mixer for bit-perfect, lossless playback.
  • Gapless, with crossfade if you want it.

Small when you want it

  • The layout changes as you resize the window.
  • A compact player and a mini player, both able to stay on top.

Looks after itself

  • Updates itself and tells you what’s new. Switch back to an earlier version if something breaks.
  • Undo for things like replacing the queue, and a full listening history.

The server stays in charge

WinSqueeze only follows it.

Nothing to install on the server

It reads the library through Lyrion’s standard interface and plays like any other Squeezebox player.

Several servers

Keep a profile for each server and switch between them.

Install or run portable

Installs per user (no admin needed), or run the portable version from anywhere.

About the developer

Hello, I’m Mat, from London. I’m a music grad, pianist, and as someone who has owned and used Squeezebox devices since 2005 you can imagine, a bit of a serious music fan.

I wrote this app primarily for me, but I hope you like it too.

Computer Science was my first degree and I’ve been coding since 1988. But you may have guessed AI tools were involved somewhat in the production of WinSqueeze’s code. Please don’t let that put you off. I’m a critical and careful user of AI, and value human decisions far more than computer-made ones. And so my approach is this: human-led design and human-checked code.

If something is wrong, or could be improved, please let me know in GitHub Discussions.
